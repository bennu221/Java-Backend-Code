# README – Simple Explanation

## Section A: Basics

### Q1. Prime & Perfect Number

* Read one number from the user.

* Check if it has only two factors → Prime.

* Add all divisors of the number.

* If the sum is equal to the number → Perfect Number.

### Q2. Fibonacci Series

* Read the number of terms.

* Start with `0` and `1`.

* Print each next number by adding the previous two.

## Section B: Arrays

### Q3. Array Operations

* Store 10 numbers in an array.

* Find the second largest number.

* Count how many times each number appears (frequency).

* Print the numbers that are repeated (duplicates).

## Section C: Strings

### Q4. String Operations

* Read a sentence.

* Count the number of words.

* Count the number of vowels.

* Change the first letter of every word to a capital letter (Title Case).

### Q5. Palindrome

* Read a string.

* Ignore spaces and uppercase/lowercase letters.

* Compare it with its reverse.

* If both are the same, print Palindrome.

## Section D: Constructors

### Q6. Product Class

* Create a `Product` class with 4 fields.

* Use a no-argument constructor for default values.

* Use a parameterized constructor to set all values.

* Use constructor chaining (`this`) to call another constructor.

* Create 3 objects and display their details.
